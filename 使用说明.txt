==================================================
          邮件群发脚本 · 使用说明（接收者版）
==================================================

收到本文件夹后，请按下面顺序操作：
  第一步 安装 Python
  第二步 改名并填写配置文件（必做！）
  第三步 准备客户名单
  第四步 运行

--------------------------------------------------
一、文件清单
--------------------------------------------------
mailer.py            主脚本
config.example.json  ★配置模板 —— 必须改名为 config.json
                     才能使用！（脚本只认 config.json）
template.html        邮件正文模板，{{姓名}} 占位符自动替换
recipients.csv       客户名单示例（你可以替换成自己的数据）
使用说明.md / .txt    本文档

--------------------------------------------------
二、第一步：安装 Python（每台电脑只需一次）
--------------------------------------------------

重要：不要双击 mailer.py！
  没装 Python 时双击不会弹出安装提示，只会跳
  "选择打开方式"或窗口一闪而过，也无法输入参数。

1. 打开官网下载页：
   https://www.python.org/downloads/
   点击黄色按钮下载安装包。

2. 运行安装包：
   - 先看界面最底部，勾选 "Add Python to PATH"
     （默认不勾！不勾的话后面命令全都用不了）
   - 再点 "Install Now"，装完点 Close

3. 打开命令行窗口（任选一种）：
   方式A：打开本文件夹，空白处按住 Shift + 鼠标右键，
          选"在此处打开 PowerShell 窗口"
   方式B：按 Win + R，输入 cmd 回车，
          再输入 cd /d 文件夹路径 回车

4. 验证：输入 py --version 回车
   显示 Python 3.x.x 即成功；
   找不到命令就换 python 再试；都不行说明
   安装时没勾 Add to PATH，需重装。

--------------------------------------------------
三、第二步：改名并填写配置（★必做）
--------------------------------------------------

1. 把 config.example.json 改名为 config.json
   （方法：右键文件 → 重命名，把 .example 删掉）

2. 用记事本打开 config.json（右键 → 打开方式 → 记事本），
   填入你自己的信息：

   腾讯云SES.SecretId     你的 API 密钥 ID
   腾讯云SES.SecretKey    你的 API 密钥密码
   腾讯云SES.模板ID       你的 SES 模板 ID（纯数字）
   发信人地址             SES 控制台创建的发信地址
   发信人显示名           收件箱里显示的发件人名称
   回复地址               收回复邮件的邮箱
   邮件主题               支持 {{姓名}} 等变量

   ⚠️ 不改名、不填密钥，脚本无法发送！

3. 这些密钥和模板来自你自己的腾讯云账号，需要先完成
   （一次性工作，控制台照引导做）：
   ① 腾讯云注册 + 实名认证
   ② 开通"邮件推送 SES"，添加你的发信域名，
      按控制台给的值在域名解析里添加验证记录
   ③ 创建发信地址（如 notice@你的域名）
   ④ 新建发信模板（正文直接粘贴 template.html 内容，
      变量写法一样都是 {{变量名}}），提交审核（约1个工作日）
   ⑤ 访问管理 CAM → API密钥管理 → 新建密钥，
      并给密钥授权 QcloudSESFullAccess 权限

--------------------------------------------------
四、第三步：准备客户名单 recipients.csv
--------------------------------------------------
- 必须有两列：邮箱、姓名（缺了会报错中止）
- 其他列随意加，如：称呼、订单号、优惠码，
  模板里用 {{列名}} 取对应数据
- Excel 编辑后直接保存为 CSV，编码自动识别

--------------------------------------------------
五、第四步：运行（按顺序执行）
--------------------------------------------------

Windows 下用 py 开头，找不到命令换 python。

第1步 预览（不发送，检查称呼和内容）：
   py mailer.py --preview 3

第2步 自测（发到你自己邮箱，检查格式和垃圾箱）：
   py mailer.py --test 你的邮箱@qq.com
   用名单第N行渲染：加 --row N

第3步 小批量试发10封：
   py mailer.py --send --limit 10

第4步 正式群发（要求输入 yes 确认）：
   py mailer.py --send

中断后重跑 py mailer.py --send，
已成功的自动跳过，不会重复发送。

--------------------------------------------------
六、安全机制（为什么不会发错人）
--------------------------------------------------
1. 发送前校验：邮箱格式错、姓名空、邮箱重复 → 中止
2. 模板变量缺数据 → 中止，不发残缺邮件
3. 必须先预览、先自测，才能正式发送
4. --send 要手动输入 yes 才开始
5. 断点续发：重跑自动跳过已成功的客户
6. 错误分类：永久失败不重试，临时限流自动等待继续

--------------------------------------------------
七、常见问题
--------------------------------------------------

Q: 双击 mailer.py 没反应？
A: 不要双击！按第二节打开命令行运行。

Q: 报"未配置腾讯云SES的 SecretId"？
A: config.example.json 没改名成 config.json，
   或者密钥没填/填错。

Q: 报"模板ID"错误？
A: config.json 里 模板ID 没填，或模板还没过审核。

Q: 想改邮件内容？
A: 改 template.html 和 config.json 的"邮件主题"；
   正文改动需同步到腾讯云模板重新审核后才生效。

Q: 想改发件人显示名？
A: 改 config.json 的"发信人名称"，立即生效。

Q: 部分客户没收到？
A: 看 发送记录.csv，"失败(永久)"多半是邮箱地址错。

Q: 新域名邮件进垃圾箱？
A: 正常。先"标记为不是垃圾邮件"，每天少量发送养信誉，
   别第一天就群发上千封。
